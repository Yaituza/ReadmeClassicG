Srujans Fantasy classic game assignment

CONTROLS:
**Arrow keys** for menu navigation (including screens like main menu)
**WASD** for overworld movement 
**Enter** for select
**Backspace** for back (only for combat)
**I** lowers volume **O** raises volume
Holding **Shift + G** in the main menu will bring you straight to the game over screen
**Tab** in Overworld/Dungeon to open the menu

The documents folder contains the Game Analysis Document, Concept Art, and Wireframes.
The build folder contains the playable Unity game
